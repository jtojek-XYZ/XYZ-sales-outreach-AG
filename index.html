Acquire a Client ID from your Google Cloud Console. Enable Gmail API and Google Sheets API.

How do I get a Client ID for our team?
  1. Go to the Google Cloud Console.
  2. Create a project (e.g. XYZ Outreach) and enable both the Gmail API and Google Sheets API.
  3. Configure your OAuth Consent Screen. Set user type to Internal (so only your @wearexyz.com / @wearexyz team can use it).
  4. Under Credentials, click Create Credentials → OAuth Client ID → Web Application.
  5. Under Authorized JavaScript origins, add this local URL: http://localhost:8000
  6. Copy the generated Client ID (which ends with .apps.googleusercontent.com) and paste it in the field above!
